# Automated Data Cleaning & Reporting

## Overview

This project is a Python-based data cleaning and reporting tool that processes raw CSV data, handles common data quality issues, validates the cleaned data, and generates summary reports and visualizations.

The project demonstrates practical data preprocessing, validation, analysis, and reporting using Python and Pandas.

## Features

- Detects missing values
- Handles missing Age, Email, and Salary values
- Detects and removes duplicate records
- Standardizes department names
- Validates Age and Salary values
- Generates department-wise employee and salary summaries
- Creates a salary visualization
- Generates automated data cleaning reports
- Saves cleaned data and reports as output files
